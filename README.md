🌟 Tính năng chính
Ứng dụng được xây dựng trên ngôn ngữ Python, tích hợp giao diện người dùng trực quan (GUI) với đầy đủ các yêu cầu từ cơ bản đến nâng cao:

1. Phần cơ bản
Vẽ đồ thị trực quan: Hiển thị cấu trúc đồ thị dựa trên dữ liệu nhập vào (NetworkX & Matplotlib).

Lưu đồ thị: Hỗ trợ xuất dữ liệu và báo cáo kết quả ra file định dạng .txt.

Tìm đường đi ngắn nhất: Triển khai thuật toán Dijkstra.

Duyệt đồ thị: Tích hợp các chiến lược duyệt theo chiều rộng (BFS) và duyệt theo chiều sâu (DFS).

Kiểm tra đồ thị hai phía: Xác định đồ thị có phải là đồ thị phân đôi (Bipartite) hay không.

Chuyển đổi biểu diễn: Tự động chuyển đổi qua lại giữa Ma trận kề, Danh sách kề và Danh sách cạnh.

Đa dạng: Hỗ trợ xử lý cả đồ thị vô hướng và đồ thị có hướng.

2. Phần nâng cao (Trực quan hóa thuật toán)
Cây khung nhỏ nhất (MST): Thực hiện thuật toán Prim (7.1) và thuật toán Kruskal (7.2).

Luồng cực đại: Thuật toán Ford-Fulkerson (7.3).

Chu trình & Đường đi Euler: Triển khai thuật toán Fleury (7.4) và thuật toán Hierholzer (7.5).

🚀 Hướng dẫn cài đặt và sử dụng
Để chạy được mã nguồn trên máy tính, vui lòng thực hiện các bước sau:

Cài đặt Python: Đảm bảo máy tính đã cài đặt Python phiên bản 3.x.

Cài đặt thư viện: Mở terminal/cmd và chạy lệnh:

Bash
pip install networkx matplotlib numpy
Chạy ứng dụng:

Mở file code bằng VS Code hoặc IDLE.

Nhấn F5 hoặc nút Run để khởi động giao diện.

Tương tác:

Nhập danh sách cạnh theo định dạng: đỉnh 1, đỉnh 2, trọng số (ví dụ: A, B, 5).

Chọn "Vẽ đồ thị" để xem hình ảnh trực quan.

Chọn thuật toán tương ứng từ Menu và nhấn "Chạy thuật toán".
